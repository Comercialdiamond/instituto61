# Instituto 61 - Site institucional

Suba todos os arquivos e pastas desta pasta diretamente na raiz do repositório.

A estrutura correta é:

```text
index.html
quem-somos.html
projetos.html
parceiros.html
doacao.html
contato.html
transparencia.html
assets/
```

A pasta `assets/` é obrigatória. Ela contém CSS, JavaScript, imagens e documentos.
